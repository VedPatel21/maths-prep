							563 text THE COMPLETE EXPLANATION
							564 text A pivot in every row answers an existence question for all right-hand sides. A pivot in every column answers uniqueness of inputs. Write the words 'row/output/existence' and 'column/input/uniqueness' beside a rectangular matrix before deciding.
							565 text A free coefficient variable yields infinitely many solutions only when the system is consistent. First search for an impossible row. A zero row 0 = 0 adds no constraint; a row 0 = 1 rules out all solutions.
							566 text A vector equation uses the supplied vectors as columns, not rows. The unknown weights become input entries. Original pivot columns are found by their indices; reduced columns generally have different entries and should not be substituted as the original vectors.
							567 text A zero vector in a collection guarantees dependence; a nonzero vector does not guarantee independence of a collection. A dependence relation needs weights not all zero. A theorem about all inputs needs a general proof; a failed universal statement needs only one valid counterexample.
							568 text Matrix multiplication is row by column, not entrywise. Inner dimensions must match. You may regroup associative products but may not reorder factors. Transpose and inverse reverse the order of products. Cancellation needs an invertible factor in the correct position.
							569 text Inversion requires a square matrix. For a 2 × 2 matrix check ad - bc before dividing. For row reduction carry the whole identity block with every operation. Verify against the original A, especially when the source contains a typographical discrepancy.
