# Navigation readability update

The top navigation now uses 18px labels on desktop and 15–16px labels on narrower screens, with targets at least 44px tall. Sidebar chapter links increased from 12px to 16px. Search, chapter group labels, breadcrumb links, and in-chapter navigation also increased in size.

On narrow screens, the header uses two rows: the brand and Chapters button above, with all four main destinations below. Header offsets, the chapter drawer, and reading-area spacing were adjusted together. This provides room for the larger text and keeps Cheat Sheet visible.

The HTML and complete package were rebuilt. The existing academic preservation audit passed after this CSS-only update. No additional browser/device checks were performed, following the user's instruction to stop those checks; earlier screenshots document the preceding navigation sizes.
