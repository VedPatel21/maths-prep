								1183 container 1 Is there an echelon row [0 … 0 | c], c ≠ 0? →
								1184 container 2 Yes: no solution. No: the system is consistent. →

								1186 container 4 None: unique. At least one: infinitely many.
							1187 text THE COMPLETE EXPLANATION
							1188 text Theorem (supplied Theorem 2).
							1189 text A linear system is consistent if and only if the last column of its augmented matrix is not a pivot column. Equivalently, no echelon row is [0,...,0 | c] with c ≠ 0. Once consistency is established, the solution is unique exactly when there are no free coefficient variables; it is infinite exactly when there is at least one free coefficient variable.
							1190 text Why does the theorem work? A last-column pivot corresponds to an impossible equation. Without such a row, free variables can be assigned values and the pivot equations can be solved backward, which constructs a solution. With no free variables the construction has no arbitrary choices. With a free variable, changing that coordinate changes the solution itself, so infinitely many solutions result.
							1191 text A zero coefficient row does not by itself prove either inconsistency or infinitely many solutions. Its constant determines whether it is a contradiction. The number of nonzero coefficient pivots relative to the number of unknowns determines whether free variables remain.
