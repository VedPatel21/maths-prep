Remember. The original entry at position (1,1) is 0. A pivot position is a location, not a promise
about that original number.
A pivot position in A is the row-column location corresponding to a leading 1 in RREF(A). A pivot
column is an original column containing such a position. The original entry at a pivot position can
be zero: the position is identified through reduction. A pivot used during elimination is the
nonzero entry currently used to cancel entries, so its numerical value can change with the
sequence of operations.

The supplied uniqueness theorem states that every matrix has exactly one RREF among its row-
equivalent matrices. REF is not unique, because multiplying a nonzero row by 2 may preserve its
staircase shape. The RREF conditions remove that scaling freedom and all entries above pivots.
More deeply, row equivalence preserves all constraints, and RREF is a canonical way to record
which earliest variables are determined by later ones. The following supplementary proof
explains that uniqueness rather than trying to establish it by numerical examples.

The proof in three connections

Why two different RREF answers cannot both be right
We need one temporary piece of vocabulary. The row span of a matrix means all linear
combinations of its rows, treated as horizontal lists. This is the same weighted-sum idea
used for column vectors later in Section 1.3. Row operations do not change the row span.
A new row is a combination of old rows, so every new-row combination is an old-row
combination. Reversibility gives the opposite inclusion. Therefore row-equivalent matrices
have exactly the same row span.

the first row in the combination whose weight is nonzero. Its leading pivot is the first
nonzero coordinate of the resulting list: all earlier row weights are zero, and all later rows
are zero to the left of their own later pivots. Consequently the possible first-nonzero
coordinate locations of vectors in the row span are precisely the pivot-column indices.
Since R and S have the same row span, they have the same pivot columns, in the same
order.
Now compare row i of R with row i of S. Their entries in every common pivot column
agree: both have 1 at their own pivot and 0 at the other pivots. Their difference is in the
common row span and is zero at every pivot coordinate. But any row combination in R
has, in pivot column j, exactly the weight on the corresponding pivot row: the pivot
columns are identity columns. If all those coordinates are zero, every row weight is zero,
so the entire combination is zero. Thus the difference between the two compared rows
must be zero. All corresponding nonzero rows agree, and both matrices place their
remaining zero rows at the bottom. Hence R = S. This proves uniqueness while allowing
different intermediate operations and different ordinary echelon forms.

THE COMPLETE EXPLANATION
Start at the leftmost column containing a possible nonzero pivot. Interchange rows if needed.
Use a nonzero pivot to clear entries below it. Move down one row and right to the next possible
pivot column. Continue to REF. This is the forward phase. If a column has no available nonzero
entry below the previous pivots, skip it; do not force a pivot there.
For the backward phase, start at the rightmost pivot, scale its row to make the pivot 1, and clear
entries above it. Continue upward and leftward. Normalizing a pivot earlier, as many examples
here do, is also valid. Arithmetic convenience determines the order; preserving the equations
determines validity.

2.7 Existence and uniqueness theorem
23/10/26, 10:58 PM2. Section 1.2 - Row reduction and echelon forms · Study Corner
Page 26 of 32file:///Users/vedpatel/Desktop/Heli-exam_prep/output/MATH2255-Visual-Study-Reader-Final.html#learn/section-1-2
SEE THE IDEA
Existence first. Uniqueness second.
Use two separate decisions, in that order.
THE COMPLETE EXPLANATION
Theorem (supplied Theorem 2).
A linear system is consistent if and only if the last column of its augmented matrix is not a
pivot column. Equivalently, no echelon row is [0,...,0 | c] with c ≠ 0. Once consistency is
established, the solution is unique exactly when there are no free coefficient variables; it
is infinite exactly when there is at least one free coefficient variable.
Why does the theorem work? A last-column pivot corresponds to an impossible equation.
Without such a row, free variables can be assigned values and the pivot equations can be solved
backward, which constructs a solution. With no free variables the construction has no arbitrary
choices. With a free variable, changing that coordinate changes the solution itself, so infinitely
many solutions result.
A zero coefficient row does not by itself prove either inconsistency or infinitely many solutions.
Its constant determines whether it is a contradiction. The number of nonzero coefficient pivots
relative to the number of unknowns determines whether free variables remain.
