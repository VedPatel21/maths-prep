							321 text We need one temporary piece of vocabulary. The row span of a matrix means all linear combinations of its rows, treated as horizontal lists. This is the same weighted-sum idea used for column vectors later in Section 1.3. Row operations do not change the row span. A new row is a combination of old rows, so every new-row combination is an old-row combination. Reversibility gives the opposite inclusion. Therefore row-equivalent matrices have exactly the same row span.

							2226 container 2 Yes: no solution. No: the system is consistent. →

						2229 text THE COMPLETE EXPLANATION
						2230 text Theorem (supplied Theorem 2).
						2231 text A linear system is consistent if and only if the last column of its augmented matrix is not a pivot column. Equivalently, no echelon row is [0,...,0 | c] with c ≠ 0. Once consistency is established, the solution is unique exactly when there are no free coefficient variables; it is infinite exactly when there is at least one free coefficient variable.
						2232 text Why does the theorem work? A last-column pivot corresponds to an impossible equation. Without such a row, free variables can be assigned values and the pivot equations can be solved backward, which constructs a solution. With no free variables the construction has no arbitrary choices. With a free variable, changing that coordinate changes the solution itself, so infinitely many solutions result.
						2233 text A zero coefficient row does not by itself prove either inconsistency or infinitely many solutions. Its constant determines whether it is a contradiction. The number of nonzero coefficient pivots relative to the number of unknowns determines whether free variables remain.
